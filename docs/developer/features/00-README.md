# Features

Complex services and user-facing capabilities in Argon.

## Overview

Features in Argon are organized by the user-facing capabilities they provide. Each feature includes:
- **What**: One-sentence description of what the feature does
- **Why**: Why this feature exists
- **Key Files**: Main source files that implement the feature
- **Flow**: High-level flowchart and detailed sequence diagrams
